# Candidate build

هذا المجلد مخصص لنسخة التحديث التي تصل إلى **المالك أولًا**.

عند تجهيز إصدار جديد، ضع نسخة كاملة من ملفات التطبيق هنا (index.html, app.css, app.js, config.js, manifest.webmanifest, sw.js)، وعدّل رقم الإصدار في `config.js` و`sw.js`.

بعد رفعها إلى GitHub، أنشئ الإصدار المرشح من لوحة المالك وحدد `/candidate/` كمسار الاختبار. لا تنشره للمستخدمين قبل إنهاء الاختبار والاعتماد.
